# TAD Chat
A chat app formatted as a forum made for students in my grade to communicate. It is dedicated to @geoffrey-wu

## Contributing
Please see the [contributing guidelines](./CONTRIBUTING.md) for more info about how to contribute to TAD Chat

## Tech Stack
TAD Chat uses:
- [Upstash Redis](https://upstash.com/) to store user & message data
- [Render](https://render.com/) to host the site
- [Vercel](https://vercel.com/) to host the subdomain
- [Express JS](https://expressjs.com/) as a framework for the backend

## Bots
You can make a custom bot to perform various things on TAD Chat. Get started [here](https://github.com/btfcookies/tad-chat-bot)
